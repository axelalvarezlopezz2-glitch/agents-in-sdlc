多くの CLI ツールと同様に、GitHub Copilot CLI には操作に使えるスラッシュコマンドが数多く用意されています。コマンドを使うと、高度な機能、内部情報、追加の構成オプションを利用できます。これまで `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などを使いました。ここでは、ほかの便利なコマンドをいくつか確認します。

このレッスンでは、次の操作を行います。

- `/context` と `/compact` で、Copilot が会話のコンテキストを管理する方法を確認します。
- `/model` で利用可能なモデルを確認します。
- `/share` でセッションをエクスポートまたは共有する方法を学びます。
- 並行作業、worktree、クラウドエージェントへの委任に使う省略可能なコマンドを確認します。

## シナリオ

CLI の主なワークフローを完了しました。次は、Copilot CLI の追加機能を使って、コンテキストを管理し、モデルを切り替えてセッションを共有します。必要に応じて [Copilot クラウドエージェント][about-cloud-agent]に作業を委任することもできます。

## Copilot CLI のコンテキストを確認する

大規模または複雑なタスクでは、モデルのコンテキストウィンドウの上限に近づく場合があります。必要に応じて Copilot CLI が会話を自動的に圧縮します。また、スラッシュコマンドを使ってコンテキストを確認したり、自分で圧縮したりできます。

1. Codespace に戻り、Copilot CLI がまだ起動していない場合は、リポジトリのルートから起動します。
2. 次のコマンドを入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム指示、ツール、メッセージ、空き領域にコンテキストがどのように分けられているかを確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を入力し、結果を比較します。会話が短い場合は、大きな違いがないこともあります。

> [!NOTE]
> コンテキストウィンドウが埋まると、Copilot CLI が自動的にコンテキストを圧縮します。自分のタイミングで圧縮したい場合は `/compact` を使います。関係のない別のタスクに切り替えて会話を新しくする場合は、`/clear` または `/new` を使います。

## モデルを選ぶ

モデルごとに得意分野が異なり、開発者によって好みも違います。Copilot CLI でモデルの一覧を表示し、使うモデルを選択できます。

1. 次のコマンドを入力します。

   ```plaintext
   /model
   ```

2. 利用可能なモデルと使用状況に関する情報を確認します。
3. 現在のモデルを使い続けるか、別のモデルを選択するか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームで協力し、学んだことを共有すると、AI ツールの活用を改善できます。`/share` コマンドを使うと、セッションを Markdown または HTML ファイルにエクスポートしたり、共有リンクを作成したり、GitHub gist を公開したりできます。

1. `/help` を入力し、インストール済みのバージョンで利用できる `/share` のオプションを確認します。
2. セッションを共有する場合は、目的に合った方法を選びます。たとえば `/share file` を使うと、Markdown ファイルとしてローカルにエクスポートできます。
3. エクスポートした内容を誰かに送信したり公開したりする前に、内容を確認します。セッションのエクスポートには、プロンプト、応答、プロジェクトの詳細が含まれる場合があります。

リンクや gist の公開は省略可能です。チームが共有を意図していないリポジトリや会話の内容を公開しないでください。

## 省略可能: 作業の拡張や委任

ワークショップの主要な流れは完了しました。Copilot CLI には大きなタスク向けのコマンドもあります。

- `/fleet` は独立したサブタスクをサブエージェントに分割し、並列実行できます。
- `/worktree` は別のタスク用に独立した Git worktree を作成できます。
- `/delegate` は Copilot クラウドエージェントにタスクを送信します。クラウドエージェントは非同期に作業し、pull request を開く場合があります。

これらのコマンドを使うと、worktree やリモート作業が追加される場合があるため、省略可能な操作です。まず範囲の明確なタスクを新しく始め、通常のワークフローに沿って結果をレビューしてください。非同期エージェントの作業について詳しく知りたい場合は、[クラウドエージェントのワークショップ][cloud-workshop]に進んでください。

- `/context` と `/compact` を使って、Copilot が会話のコンテキストを管理する方法を確認しました。
- `/model` を使って、利用可能なモデルを確認しました。
- `/share` でセッションをエクスポートまたは共有する方法を学びました。
